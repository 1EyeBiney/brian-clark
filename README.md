# Brian Clark: work history and portfolio

The site is at https://1eyebiney.github.io/brian-clark/

Four pages, one stylesheet, no scripts, no build step. Built to be read with a screen reader.

- index.html: work history, how I work, what I built, and where I stand on certification.
- features.html: things I built that you can try, each with the problem it solves.
- study.html: a study of employment and remote work among people with vision difficulty, from Census Bureau data.
- resume.html: a conventional resume, print-friendly (Ctrl+P).
- style.css: plain high-contrast styling with dark-mode and print rules.
- study-data/: the programs and output behind the study, so anyone can repeat it.

study.html is generated by a program. Do not edit its numbers by hand.

`assets/sun-demo.mp4` and `assets/sun-demo.vtt` are the SUN demonstration video and its captions, rendered from the raw recording by `../video/render_sun_demo.sh` (the raw recordings stay out of this repository).
